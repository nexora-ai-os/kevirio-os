# Google Operations Architecture
Owner/Trigger → Task Planner → AI Employee Task → Workflow Orchestrator → Capability Guard → Permission → Approval → Scope/Account → Data Classification → Quota → Provider Policy → Cost Guard → Reservation → Gateway → Adapter → Google API。

この順序は全AI Employeeが継承する。社員追加はRegistry、Capability manifest、Workflowを追加し、Platformを再設計しない。Workspace、Owner、classification、quota、approvalの不明状態は停止する。
