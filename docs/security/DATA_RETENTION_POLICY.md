# Data Retention Policy

- Auth/session: Provider-managed; revoke on account/incident.
- Sandbox cache: expire and purge by configured TTL.
- Artifacts/Memory: workspace policy; archive then verified delete.
- Evidence/Revenue/Audit: retain for business/legal substantiation; deletion/correction requires Owner-reviewed procedure.
- localStorage: remove confidential business data after verified migration.

Exact statutory periods remain Owner/legal confirmation items.
